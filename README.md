# pi-dev

个人 pi 开发工具包。

## 安装

```bash
pi install git:github.com/jeryfan/pi-dev
```

## 本地调试

```bash
pi install /Users/fanjunjie/Documents/repositories/personal/pi-dev
```

## 项目级安装

```bash
pi install -l git:github.com/jeryfan/pi-dev
```

## 更新

```bash
pi update git:github.com/jeryfan/pi-dev
```
